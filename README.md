## 📊 Quantitative Risk & Portfolio Analysis

This project contains two Python-based financial analysis tools built with **Pandas, NumPy, and yfinance**.

### 1. Quantitative Risk & Performance Metrics

Analyzes historical stock performance and risk using market data from Yahoo Finance.

The analysis calculates:

* Annualized returns
* Annualized volatility
* Sharpe ratio
* Maximum drawdown
* Correlation matrix

The project uses **AAPL, MSFT, GOOGL, and NVDA** as a sample portfolio and evaluates their historical performance over a specified period.

### 2. Stock Portfolio Analyzer

A simple portfolio analysis tool that calculates the performance of individual holdings and the overall portfolio.

It calculates:

* Total invested capital
* Current portfolio value
* Profit/Loss
* Individual stock returns
* Portfolio weights
* Best and worst performer
* Average stock return
